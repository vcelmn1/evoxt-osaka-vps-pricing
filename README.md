## 大阪三条主流线路，先确认你要的是哪一种

同样标着“大阪”，走 Premium 优化、IIJ、软银、CN2 GIA 的机器，实际体验差别很大，价格也差好几倍。

中国大陆到大阪的物理距离摆在那儿，三网延迟普遍落在 60–90ms：电信经上海出口直连软银约 85ms，联通经大阪节点约 74ms，移动要绕香港再到软银，约 88ms。三家里面联通通常最好，移动因为多一跳香港，偶尔会多几毫秒。跟美西动辄 150ms 以上比，大阪已经算近了。

**IIJ** 是日本 Tier 1 骨干运营商，和 NTT 一起撑着日本互联网骨干，与 JPIX、JPNAP 直连，国内跳数少，国际 transit 自己控制。但大阪的 IIJ 套餐基本不对中国三网做特殊优化，不配 9929、CMIN2、CN2 GIA 这类回程。买 IIJ 的人，多数是日本本地业务，或者从日本往欧美、东南亚发流量。IIJ 自营云的价格在每月 5,000 日元以上，通过使用 IIJ 上游的商家能便宜不少。

**软银线路** 是 HostDare 那一类做法，三网回程走软银，延迟数字漂亮。问题在高峰期。有商家直接在自己的购买页写明：近几年 IIJ 和软银线路使用人数激增，高峰时段会出现丢包、延迟升高、网速变慢，这属于线路本身的属性，商家没法额外优化，对稳定性要求高的话建议换东京。这类自己承认限制的说明，比任何测评都有参考价值，因为它解释了为什么白天测出来的 74ms，晚上可能变成另一种样子。

**CN2 GIA** 是搬瓦工大阪那条路，年付标价在 $499.99 这个量级，保障最足，价格也最高，跟前面几家不在一个预算段。

**Premium 档（Evoxt 这类）** 在中间位置。官方把香港和大阪放进 Premium 网络，定位是面向中国大陆的访问优化，代价是流量少、超额单价高。具体走哪家上游、路由怎么绕，定价页没有公开，这一项只能靠自己实测。

大阪和东京之间怎么取舍也有个大致规律：同线路下大阪普遍比东京便宜一截，代价是机房规模和网络资源略弱于东京。预算敏感、又不是跑关键业务，大阪更划算；要求网络资源充足，就往东京走。

## 这几种情况，Evoxt 大阪不是好选择

**你主要服务中国大陆用户，而且要求晚高峰稳定。** IIJ 和软银在高峰期会抖，这一点商家自己写在页面上。Evoxt 的 Premium 档到底优化到什么程度，官方没给路由细节，唯一稳妥的办法是先开最低档跑一周，不满意再退。

**你要跑大流量。** Premium 档超出流量 $12/TB，视频中转、镜像站、大文件分发在这里很吃亏，去选标准机房或者专门做大流量的商家更合适。

**你需要 IPv6 或 Windows。** 官方定价页没有列出这两项支持情况，下单前开工单问清楚，别默认有。

**你想要纯软银回国的线路。** Evoxt 大阪是 Premium 优化档，不是软银专线，定位不同。

- **支付方式**：官方 FAQ 列的是信用卡、借记卡、PayPal、比特币和 USDT（Tron）。有中文测评说支持支付宝，官方列表里没有这一项，结账页看到什么就是什么。
